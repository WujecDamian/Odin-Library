# Smart Owl Library

A simple web-based personal library to track your books.  
Add books, mark them as read/unread, and remove them when needed.

Project from TheOdinProject:
https://www.theodinproject.com/lessons/node-path-javascript-library

## Features

- Add new books (title, author, number of pages)
- Mark books as **read** / **not read**
- Delete books from your library
- Clean, dark-themed card layout
- Responsive grid display of books
- Uses `crypto.randomUUID()` for unique book IDs

## Technologies

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript (no frameworks)
- SVG icons for buttons
